# QR Code Generator

A simple and responsive QR Code Generator built using **HTML**, **CSS**, and **JavaScript**. This application allows users to enter any text or URL and instantly generate a QR code that can be scanned by smartphones and QR code readers.

## 🚀 Features

- Generate QR codes from text or URLs
- Clean and responsive user interface
- Instant QR code generation
- Error handling for empty input
- Lightweight and easy to use
- Works directly in the browser
